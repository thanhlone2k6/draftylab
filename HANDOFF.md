- **Never re-enable `intro` on the Trusted-by `LogoLoop`** (or any marquee that sits at the fold): the CSS pre-hide (`[data-intro] .logoloop__item { opacity: 0 }`) plus the 0.45s stagger / 0.7s fade leave the row blank, then part-filled with empty gaps, for ~1.15s after it scrolls into view — on a phone it is the first row you see.
