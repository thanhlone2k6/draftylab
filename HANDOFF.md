## Gotchas
- **`src/i18n/overrides.ts` is the place for owner changes after the review file** (currency per market, the contact-field wording). `strings.json` is generated and would lose hand edits; `tr()` applies the overrides on top.
- **Dev-only Vite trap**: a lazily-imported island (`client:visible`) can 504 on its first request when its deps were not pre-bundled — that is what made the case-study counters sit at `0.0K` on every page ("sang các ngôn ngữ khác thì không chạy"). `optimizeDeps.include` in `astro.config.mjs` prevents it; if a dev page looks dead, look for `504 Outdated Optimize Dep` in the console before blaming the code.
- **The contact field is free text** (`method: 'other'`): the form derives email/phone/instagram/other from what was typed, `lead-schema.ts` accepts any 2–120 chars as `other`, and the D1 `method` column is plain TEXT (no migration). Don't tighten it back without asking — the owner asked for it explicitly.
- **Every visible string must come from `getContent(locale)`** (`src/i18n/index.ts`) — never a bare literal in a component. `src/data/content.ts` is now only the Vietnamese source + structure/data (ids, hrefs, colours, mediaIds, brand names, urls, numbers); the other four languages live in `src/i18n/strings.json`.
- **`strings.json` and `media.json` are generated — never hand-edit them.** Edit `ngôn ngữ/CONTENT_I18N_5_LANGUAGES_REVIEW.md` (at the DFL2 root, outside `website/`) and re-run `node scripts/i18n/parse-review.mjs` then `node scripts/i18n/build-media.mjs`. `build-media.mjs` matches media strings by their **Vietnamese text**, so it survives a re-scan reordering the manifest.
- **Form option VALUES stay Vietnamese** (`INDUSTRIES/NEEDS/TEAMS/BUDGETS` in `src/data/lead-options.ts`): they are the server whitelist (`src/lib/lead-schema.ts`) and sit in D1. Only the *labels* are translated (`QuickCallForm` maps by index).
- **New pages/components must take `locale`** and be listed in `src/layouts/SiteSections.astro` (or the 404 helper). Forgetting it silently falls back to the Vietnamese dict.
- **Localised 404s need `prepare-dist.mjs`**: Astro writes `dist/<lang>/404/index.html`; the script flattens it to `dist/<lang>/404.html` (Cloudflare Pages serves the closest `404.html`).
- **The nav's open/close morph must be measured, not corner-pinned**: on phones the collapsed menu panel is centred under the pill (PillNav.css ≤899px), so the start clip box is derived from the burger's `getBoundingClientRect()` (`PillNav.tsx`, `useLayoutEffect`). Re-pinning it to `width - header` puts the menu back in the corner. The nav only folds below ~559px, so that is the range to test in.
- **`check-no-local-paths.mjs` runs inside `build:cf`** — if you add Vietnamese copy that happens to contain a banned folder name, the Cloudflare build fails with a confusing "leak detected" error. Patterns must match a *path* (`Dự án\//`), never a bare word that could be real copy.
- **Hero headline is column-sized**: `.hero__copy` is a `container-type: inline-size` container and `.hero__title` uses `min(…, 8cqi)`. Longer lines are fine now — but if you raise the `cqi` factor the headline runs under the portrait canvas again (the column is 48% of 1100px and `.hero` has `overflow: clip`).
- **How I Work titles are column-sized too**: `.hw__stage` is a query container, `.hw__name` is `min(1.2rem, 8cqi)` — 8cqi is what keeps the longest stage name off a third line. Raising it re-breaks the owner's "max 2 lines" rule.
- **How I Work folder tabs are blank on purpose**: `ProcessFolder` passes `tabLabel=""`; `Folder` keeps `label` as the accessible name and falls back to the default tab width when `tabLabel` is empty. Don't "fix" the missing tab text.
- Gallery card titles are **overridden in `content.ts` (`gallery.itemTitles`)**, not in `media.public.json` — re-running `media:build` would otherwise bring back "Content & Video Editing 01–04".
- **Never set `el.volume` directly for a `<video>` we care about** — go through `applyMediaVolume` / `applySessionVolume` (`src/lib/volume.ts`) or `window.__dflAudio.apply(el, level, muted)`. A raw `el.volume = x` is silently ignored on iOS, which is exactly the bug a previous session fixed.
- The bridge keeps the routed element at `volume = 1` and lets the gain carry the level (never attenuate twice). Muted elements are never routed (they are silent anyway) and routing waits for the first pointer/key gesture — an `AudioContext` may not start outside one, and routing into a suspended context would be silent.
- A routed element gets a `volumechange` listener that mirrors `muted` into the gain, so code that only sets `el.muted` (the lightbox's own button) still works on iOS.
- Media must stay **same-origin** for the gain path: `createMediaElementSource` outputs *silence* for CORS-cross-origin media. `/media/v2/*` is same-origin, so fine.
- **Trusted-by = two implementations, one data source** (`src/data/partners.ts`): phones = CSS marquee in `TrustedBy.astro` (6 partners × 3 rows = 18 `.tb__marq-item`, `-33.3333%` translate; keep the row count in sync with the percentage), ≥768px = `PartnerLoop.tsx` (LogoLoop dock). Do **not** put `client:visible`/`client:load` on `PartnerLoop` — `client:media="(min-width: 768px)"` is what keeps the engine off phones. Never re-enable `intro` on that LogoLoop.
- **Dev server goes stale**: after changing `content.ts`/adding a component, HMR can serve the old file (or islands fail with `504 Outdated Optimize Dep`). Fix: kill it, `rm -rf node_modules/.vite .astro`, `npm run dev`.
- `npm run test:e2e` needs a **plain `npm run build`** first: `build:cf` runs `prepare-dist`, which moves the 25 full 720p videos out of `dist/` for R2, so the lightbox tests hang against that build.
- **How I Work source folders = the ids**: renaming a subfolder under `Cách tôi sẽ làm việc/` changes every id → update `media-roles.json` (`expectFile` guard fails the test on drift) + `content.ts` `mediaIds`. The section is **images-only**; HEIC needs macOS `sips`.
- Run `astro check` (0 errors) + `npm run test:media` before pushing; copy/labels live in `src/data/content.ts`.
- `.mp4` is gitignored except `*-preview.*.mp4`; full 720p lives ONLY in R2 `draft2` (served by `functions/media/v2`). Never delete R2 `draft2` / `draftylab-media`.
- Preview and production share D1 + R2; other preview hosts fail Turnstile unless added to the widget.
- Secrets are set by the owner via `wrangler pages secret put`; never paste or commit them.
- Never touch V1 resources: R2 `draftylab-media`, project `draftylab-v2`, site `dinhhouse-website`, branch `backup-v1`, tag `v1-final-2026-10-17`.
